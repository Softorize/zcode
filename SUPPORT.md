# Support

zcode is a community-supported pre-1.0 project.

- Use [GitHub Issues](https://github.com/Softorize/zcode/issues) for reproducible
  bugs and feature requests.
- Include `zcode version`, operating system, provider/model, reproduction steps,
  and redacted logs when reporting a bug.
- Use [GitHub private vulnerability reporting](https://github.com/Softorize/zcode/security/advisories/new)
  for suspected security vulnerabilities.

There is no guaranteed response time or compatibility support for older
pre-1.0 releases. Please do not include API keys, session contents, private
repository data, or unredacted filesystem paths in public reports.
